# User flow

Start from `canvas.json` in this folder. This is one task from a start to an outcome. It is not a journey map: no phases, no emotion row, no opportunities lane.

## How to fill it

- Read left to right. A branch stacks up and down, then rejoins or ends.
- One step per node. A title and a short line are enough.
- A decision node asks one question. Label the outgoing edges with the answers, such as yes and no.
- Keep a start and at least one end. Add steps by inserting nodes, not by writing a long list inside one node.
- Use arrow endpoints so direction is obvious.
- An architecture sketch may reuse this edge style: short labels, one reading direction, arrows for dependency or flow. Drop the start and end framing when the picture is a system landscape rather than a task.
- A flowchart, sequence diagram, ERD, or class diagram stays Mermaid instead of this template.
