# Affinity map

Start from `canvas.json` in this folder. This clusters notes from research. It is not a journey: no columns, no ordered phases, no arrows unless a relationship truly matters.

## How to fill it

- One idea per sticky. A phrase, not a paragraph.
- Group stickies only when the grouping says something. Name the group with the theme, not "Group 1".
- Add or remove clusters to fit the evidence. Leave space between clusters.
- Unsorted notes stay outside the groups rather than being forced into one.
- Use the actor's words when the source has them. Label assumptions.
- Replace every placeholder.
