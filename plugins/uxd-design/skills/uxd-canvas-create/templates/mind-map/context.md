# Mind map

Start from `canvas.json` in this folder. One central idea, branches outward. It is not a journey map and not an affinity cluster.

## How to fill it

- The center is the question or topic, in a few words.
- First-level branches are the main parts of that topic. Add a second level only when a branch needs it.
- Keep labels short. Split a sentence into another branch instead of filling the center.
- Edges connect a child to its parent. Do not add arrows unless direction matters.
- Replace every placeholder.
